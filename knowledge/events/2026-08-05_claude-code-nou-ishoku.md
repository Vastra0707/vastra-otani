# 脳を移植しているから

## 発言・要点

- 講座の中で「脳を移植しているから」という表現で、自分の知識・思考のクセを
  Claude Code に構造化データとして渡し、そこから記事や投稿を生成させる手法が紹介された。
- Obsidian のグラフビュー（タグ #Event で紐づいたノート群）を知識のベースとして使い、
  ノート同士のつながりを可視化しながら蓄積している。
- Claude Code の Skills 機能を活用し、脳内トレース → X & note運用に基づいた記事作成を
  15分で完成させる事例が紹介された。
