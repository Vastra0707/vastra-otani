# 事業計画の抽出 — デザインコンサルティングの6領域と料金設計

## 発言・要点

- ミーティングの目的：大谷さんの頭の中にある「デザインコンサルティング事業計画」を言語化し、AIへ入力して体系的に整理すること。
- **サービス領域の定義（6つの柱）**：
  1. CDO（最高デザイン責任者）支援
  2. デザインマネジメント（チーム組成・採用支援）
  3. ブランディング策定
  4. クリエイティブ要件定義・仕組み化
  5. クリエイティブ制作ディレクション
  6. デザイン定義・クオリティコントロール
  → これらをパッケージ化し、営業活動が可能な状態にすることが目標。
- 提供モデル：個人の時給換算・単発受注から脱却し、パッケージ商品と個別商品を明確に区分けして顧客が選択できる体制へ。
  SES・エージェント連携で「チームでのデザインサポート」案件も獲得。
- 低単価案件（LP作成・バナー制作等）への見解：「AIの台頭や競合の多さから単価が安く、ビジネス上の優先順位は低い」
  → 6/3定例MTGでの「ちっちゃいクリエイティブ」批判と一貫。
- **料金プラン構想**：顧客の入り口として月額5万円程度の顧問プランを含む4段階（例：5万円/15万円/30万円/50万円）。
  契約期間は最低3〜4ヶ月を最適とする。
- ポートフォリオ・営業資料は顧客の許可なく公開できないため、クローズドな環境での提案が基本。

## キーワード

- CDO支援 / デザインマネジメント / ブランディング / 要件定義・仕組み化 / 制作ディレクション / クオリティコントロール
- パッケージ商品 × 個別商品
- 月額顧問プラン（5万円起点、4段階）
- クローズド提案（ポートフォリオ非公開）
