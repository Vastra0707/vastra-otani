# Vastra.Inc 正式サービス体系（顧問プラン＋実行パッケージ）

大谷さんの「デザインコンサルティング事業」が実際の料金表・契約条件まで落とし込まれた、
最も具体的な事業ドキュメント。X/note記事や営業資料の元ネタとして使う。

## ご契約までの流れ

事前ヒアリング（無料）→ 診断プラン／トライアル（10万円・1ヶ月）→ 継続顧問プラン

「事前ヒアリングにて課題の状態とお取り組みの方針を確認したうえで、ご一緒できると判断した場合に
診断プランをご案内する。ご状況によってはお引き受けを見送る場合がある」— 選別する姿勢が明記されている。

## 顧問プラン（3段階）

| プラン | 月額 | 最低契約 | 関与度 |
|---|---|---|---|
| ライト（相談役） | 20万円/月 | 3ヶ月 | 意思決定とレビュー中心。月1回MTG＋Slack |
| スタンダード（実行伴走） | 35万円/月 | 6ヶ月 | 判断を握り実務は段階的に可変。月2回MTG＋Slack常時 |
| プロフェッショナル（経営パートナー） | 60万円/月 | 6ヶ月 | 経営層に深く関与。常時伴走（週次相当）＋会議同席 |

プロフェッショナルプランの内容は「CDO相当の統括関与（実質的な外部CDO機能）」を含む
— 8/6定例MTGで議論された「CDO」概念がここに実装されている。

## 状態別・パッケージの選び方フレームワーク

顧客の課題を6状態に分類し、入口パッケージを提示する構造：

| 状態 | よくある悩み | おすすめの入口 |
|---|---|---|
| F：課題が未定義 | デザインが弱い気がするが、何が問題か分からない | 診断パッケージ（10万円） |
| A：採用のつまずき | デザイナーの採用・評価ができない | 診断→デザイン組織・内製化パッケージ |
| B：制作の属人化 | 発注ごとに品質が揺れ、トーンが割れる | 診断→顧問スタンダード |
| C：経営局面 | リブランド・新規事業・資金調達・上場準備 | ブランド立ち上げ／プロダクト0→1パッケージ |
| D：外注の手綱 | 制作物の良し悪しが判断できない | UX改善・グロースパッケージ |
| E：内製化の設計 | 内製化したいが体制設計ができない | デザイン組織・内製化パッケージ |

## 実行パッケージ（一部）

- ブランド立ち上げ：人月50〜100万円、目安2〜4ヶ月
- コーポレートサイト構築：グランドデザイン20万＋ページ単価、目安2〜3ヶ月
- LP・販促クリエイティブ：LP20万円〜／バナー5,000円〜、目安3〜6週間（スポット対応向け）
- UX改善・グロース：人月50〜100万円、目安2〜3ヶ月
- プロダクト0→1：人月50〜200万円、目安3〜6ヶ月（開発まで一気通貫）
- デザイン組織・内製化：人月50〜100万円（顧問プロフェッショナルの中核領域）
- 運用・保守：月額1.5万円〜（ストック収益型、他パッケージ後の継続に最適）

## 契約条件（共通）

- 契約形態：準委任契約（成果物請負ではなく関与・稼働への対価）
- 更新：最低契約月数経過後は月単位自動更新
- プラン変更：アップグレードは随時、ダウングレードは契約更新時のみ
- 成果保証はしない（「専門的知見に基づき誠実に伴走するが、事業成果は市場環境や社内体制など
  複数の要因に左右されるため契約上の成果保証は行わない」）
- オンライン対応（全国・海外企業）

## note/X記事のネタとして使える観点

- 「診断プラン10万円」という“お試しではない、課題を定義するための入口”という設計思想
- ストック（運用・保守月額）とスポット（LP・ブランド立ち上げ）を両輪にした収益構造
  （6/9定例MTGの「ストック型×スポット型」議論の実装形）
- 状態別フレームワーク（F/A/B/C/D/E）はそのまま「あなたの会社はどのタイプ？」的な診断コンテンツに転用できる
