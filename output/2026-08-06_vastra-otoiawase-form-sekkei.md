# Vastra お問い合わせフォーム 項目設計書

Google Formsへの直接アクセス手段がないため、このドキュメントを見ながら
Googleフォーム上に手動で項目を作成することを想定した設計書です。
大谷さんの発言ノート（事業計画・営業方針）を反映しています。

## 設計方針（ノートからの根拠）

- Vastraは「デザインコンサルティング」に特化。LP制作・バナー制作等の
  「ちっちゃいクリエイティブ」単発案件は優先度低い方針
  （`2026-06-03_teirei-mtg.md`, `2026-06-05_jigyokeikaku-chushutsu.md`）。
  → フォームの相談カテゴリはコンサルティング6領域を主軸にし、
  制作単体の依頼は選べるが優先度が低いことが分かる並びにする。
- サービスは以下6領域で構成（`2026-06-05_jigyokeikaku-chushutsu.md`）：
  CDO支援 / デザインマネジメント（採用・チーム組成） / ブランディング策定 /
  クリエイティブ要件定義・仕組み化 / クリエイティブ制作ディレクション /
  デザイン定義・クオリティコントロール
- 料金は月額顧問プラン4段階（5万/15万/30万/50万円）、契約期間最低3〜4ヶ月が基本
  （`2026-06-05_jigyokeikaku-chushutsu.md`）。
  → 予算感を早い段階でヒアリングし、ミスマッチを防ぐ設問を入れる。
- ポートフォリオ・営業資料はクローズド前提（`2026-06-05_jigyokeikaku-chushutsu.md`）。
  → フォーム上で機密保持や資料共有の可否を確認する一言を添える。
- 大谷さん本人は「対人コミュニケーションは信頼関係があるものは1回チェックを入れる」
  というスタンス（`2026-06-05_tachiage-sodan.md`）。
  → 新規問い合わせは一次対応後、大谷さんが最終確認するフローを前提にする
    （フォーム自体に自動返信文言を入れておく）。

### 追加の設計方針（脳内マップより, 参考情報）

- 「結局、俺のマンパワーがめっちゃ必要になるっていう状況がめんどくさい。仕組みにしてみんなで
  動いてもらって、俺はクロージングだけしたい」（定例MTG 6/22）
  → フォーム自体を一次スクリーニングの「仕組み」として機能させる設計が本人の志向と一致する。
  予算感・契約期間・相談カテゴリを事前に細かく聞く構成はこの方針の裏付けとして維持する。
- 「普通のLPあんま作りたくない。根幹から変えたい」（登記直前MTG 7/1、チャットUI構想）
  → 将来的にHPの問い合わせ導線がチャット的なUIに変わる可能性がある。今回のGoogleフォームは
  その前段の実用的な受け皿と位置づけ、恒久仕様として作り込みすぎない（後で置き換え前提）。
- 「顔採用ですもん。基本、人って入る理由とやめる理由が一緒になる」「キーマンへの接点強度」
  （採用哲学 6/17）＋ リファラル20%報酬（`2026-06-05_tachiage-sodan.md`）
  → 紹介経由の問い合わせを重視する姿勢が一貫している。Q11「どちらでお知りになったか」で
  「紹介」を選んだ場合に紹介者名を聞く分岐を追加する（下記Q11参照）。
- 「AIが出したものをそのまま垂れ流しにしてるのは意味がない。人の目が介在してないと
  AI生成もパクりも一緒」（AI利用のマナー 6/22）
  → フォーム経由の問い合わせも、内容を大谷さん自身が最終的に目を通す前提を崩さない
  （すでに冒頭の設計方針に記載の「最終確認」フローと整合）。

## 質問項目

### 1. お名前（必須）
- 種類: 記述式（短文）

### 2. 会社名・屋号
- 種類: 記述式（短文）
- 説明: 個人でのお問い合わせの場合は空欄で構いません

### 3. メールアドレス（必須）
- 種類: 記述式（短文）
- 検証設定: メールアドレス形式

### 4. 電話番号
- 種類: 記述式（短文）

### 5. ご相談内容（必須・複数選択可）
- 種類: チェックボックス
- 選択肢:
  1. CDO（最高デザイン責任者）支援
  2. デザインマネジメント（チーム組成・採用支援）
  3. ブランディング策定
  4. クリエイティブ要件定義・仕組み化
  5. クリエイティブ制作ディレクション
  6. デザイン定義・クオリティコントロール
  7. その他制作のご相談（バナー・LP等）
  8. 業務提携・協業のご相談
  9. まだ相談内容が明確でない・壁打ちしたい

### 6. ご相談内容の詳細（必須）
- 種類: 記述式（段落）
- 説明: 現状の課題や、実現したいことをできるだけ具体的にご記入ください。

### 7. ご予算感（目安）
- 種類: ラジオボタン
- 選択肢:
  1. 〜月額5万円程度
  2. 月額15万円程度
  3. 月額30万円程度
  4. 月額50万円以上
  5. スポット（単発）でのご相談
  6. 未定・ご相談したい

### 8. ご契約を想定している期間
- 種類: ラジオボタン
- 選択肢:
  1. 3〜4ヶ月程度
  2. 半年〜1年程度
  3. 単発・短期のみ
  4. 未定

### 9. ご希望の開始時期
- 種類: ラジオボタン
- 選択肢:
  1. すぐにでも
  2. 1ヶ月以内
  3. 3ヶ月以内
  4. 未定

### 10. 資料・秘密保持について
- 種類: ラジオボタン
- 説明: 過去のご支援実績はクローズドな形でのご紹介となります。
- 選択肢:
  1. 秘密保持契約（NDA）を締結の上で資料共有を希望する
  2. 現時点では不要
  3. 詳細を相談したい

### 11. どちらでVastraをお知りになりましたか
- 種類: ラジオボタン（「セクションに移動」で分岐設定）
- 選択肢:
  1. 紹介（リファラル） → 「11a. 紹介者のお名前」セクションへ
  2. SNS（X / note等） → 次の質問へ
  3. Webサイト・検索 → 次の質問へ
  4. その他 → 次の質問へ

### 11a. 紹介者のお名前（任意）
- 種類: 記述式（短文）
- 説明: Q11で「紹介」を選んだ場合のみ表示するセクション（Googleフォームのセクション分岐機能を使用）
- 補足: 大谷さんの「顔採用」「キーマンへの接点強度」を重視する方針と、リファラル報酬20%の
  運用（`2026-06-05_tachiage-sodan.md`）を踏まえ、紹介経由の問い合わせを識別できるようにする。

### 12. その他ご質問・ご要望
- 種類: 記述式（段落）
- 必須ではない

## Googleフォーム作成時の設定メモ

- 「回答を1回に制限する」はオフ推奨（法人代表者以外からの複数問い合わせもあり得るため）
- 回答をスプレッドシートにリンクし、通知メールを担当者宛に設定
- 必須項目: 1, 3, 5, 6（上記参照）
- Q11は「紹介」選択時のみQ11aセクションに分岐させる（Googleフォーム編集画面で
  選択肢右下の「セクションへ移動」プルダウンから設定）
