# otani-voice

`knowledge/events/` にある大谷さんの発言・知識ノートを読み込み、大谷さんらしい語り口で
X（旧Twitter）投稿またはnote記事の下書きを生成するSkill。

## 手順

1. `knowledge/events/*.md` を読み、ユーザーが指定したテーマ・キーワードに合致するノートを選ぶ
   （テーマ未指定の場合は最新のノートを使う）。
2. ノート内の「発言・要点」「引用」を素材として、大谷さんの一人称・語り口を再現する。
   - 誇張しすぎず、ノートに書かれていない事実は創作しない。
   - 引用（`>` ブロック）のニュアンスは可能な限り活かす。
3. 出力形式をユーザーに確認する（未指定なら両方作る）:
   - **X投稿案**: 140字程度、3案
   - **note記事案**: 見出し付きの本文（800〜1500字程度）
4. 生成した下書きを `output/YYYY-MM-DD_<テーマ>.md` に保存する。
5. 保存後、ユーザーに内容を提示し「そのまま投稿はせず、必ずレビュー・編集してから使ってください」
   と伝える。

## 制約

- 実際のX/note APIへの自動投稿は行わない（このSkillは下書き生成のみ）。
- 外部API・有料サービスを新たに使う必要が出た場合は、実行前に必ずユーザーに確認する。
